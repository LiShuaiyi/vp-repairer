## Priority 5: Benign/Environment Warnings To Keep Separate

- `MIQP planner is unavailable ... falling back to QP planner`: Gurobi license/HostID mismatch; it changes the planner backend and can affect repair success, but it is not a monitor TV bug.
- `route planner failed; reusing fallback ego reference path from monitor world`: route planner fallback; relevant for geometry/CLCS debugging, not direct TV computation.
- `domain_dict construction failed ... DynamicObstacle has no attribute get_lane`: DomainDPLL falls back to empty domains; not a crash, but means DomainDPLL often behaves like plain DPLL plus overhead.
